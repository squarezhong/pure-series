# Pure Series

一次安装，按站点自动启用 Pure 系列网页净化脚本。

**[安装 Pure Series](https://raw.githubusercontent.com/squarezhong/pure-series/main/pure-series.user.js)** · 当前聚合版本：`1.0.1` · 包含 8 个脚本

## 安装与更新

1. 安装 Tampermonkey，再点击上方安装链接。
2. 停用已安装的对应单站 Pure 脚本，避免重复执行。
3. 打开支持的网站，通过 Tampermonkey 菜单调整设置。原单站脚本的设置不会自动迁移。

后续更新由 Tampermonkey 自动检查。
